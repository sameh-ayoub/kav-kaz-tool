# kav-kaz-tool

اول اداه سبام بوت من غير دخول البوت السيرفر
![](pack.png)

## طريقه التحميل والتشغيل للويندوز

### 1. تحميل بايثون

تروح الموقع حق بايثون:

https://www.python.org/downloads/

موجود في روم الديسكورد

### 2. التحقق من اصدار بايثون

بعد ماتحمل بايثون تفتح cmd في نفس المجلد حق التحميل وتكتب:

```
python3 --version
```

بيظهرلك الاصدار مثلا 3.11.9

### 3. تحديث pip

```
python3 -m pip install --upgrade pip
```

### 4. تثبيت المكتبات

```
python3 -m pip install discord.py customtkinter cryptography Pillow requests certifi aiohttp
```

### 5. تشغيل الاداه

وفي نفس ال cmd تكتب:

```
python3 main.py
```

### 6. 
بعدها تروح الموقع ذا عشان تجيب توكن بوتك : https://discord.com/developers/applications
